# Lord of Mysteries Project

## Identity

- **Project name:** Lord of Mysteries
- **Slug:** `lord-of-mysteries`
- **Status:** project workspace initialized
- **Primary language:** English for repository content; localized game display text may be added when authoritative source data is available

## Scope

This project is reserved for Lord of Mysteries-related work. Future artifacts should cover only the game's product direction, information architecture, visual design, content model, data contract, assets, and implementation requirements.

The project may eventually include:

- A Lord of Mysteries game hub and navigation model
- Interactive map and location data
- Character, pathway, item, quest, and encounter references
- Localized content and game-specific imagery
- Lord of Mysteries-specific frontend, tooling, and backend integration

## Boundaries

- Keep Lord of Mysteries assets and specifications under this project directory until an implementation location is explicitly approved.
- Reuse shared Arkive platform conventions only when they do not introduce another game's content or assumptions.
- Do not copy AION2, Palworld, STS2, V Rising, Lost Ark, or unrelated portal content into this project.
- Do not modify another game's app, data pipeline, resource set, changelog, or design artifact as part of Lord of Mysteries work.
- Treat game facts and display names as source data; do not invent canonical lore or mechanics without marking them as placeholders.
