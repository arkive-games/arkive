## Production credits

Replace the disclaimer-focused About body with contributors. Derive the initial
list from change submissions; allow manual additions/corrections, including
non-code contributions. Keep generated data and manual adjustments distinguishable
so refreshes preserve manual maintenance.

Credits cover direct work on the current game's site content/features only.
Shared-component/platform work belongs to platform production and does not qualify
someone for a game's credits merely because the game uses it. A person with
separate direct game contributions qualifies through that work. Manual entries
follow the same scope. Attribution/editor mechanics remain open; no generation
pipeline is claimed to exist.

## History, contact, and filing

- Version History links to this game's site changelog and the Arkive platform
  changelog. These record website changes, not publisher patches. Shared changes
  remain once in platform history instead of being copied to game histories;
  follow `product_model.game_about` / `platform_history` in the site specification.
- Discussion and Feedback uses centrally maintained platform wording and the
  configured QQ number; no number or final wording is invented here.
- The fullscreen map has no footer, so About carries the host's applicable ICP
  record. Retain existing host-ownership and third-party-host exceptions.
